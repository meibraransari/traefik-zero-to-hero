# Contributing to Traefik — Zero to Hero Guide

Thank you for your interest in contributing to the project! We welcome contributions of all kinds, including documentation updates, example configurations, troubleshooting steps, and grammar fixes.

## How to Contribute

1. **Fork the Repository**: Create a personal fork of the project on GitHub.
2. **Clone the Fork**: Clone your fork to your local machine:
   ```bash
   git clone https://github.com/your-username/markdown-manager.git
   ```
3. **Create a Branch**: Create a new branch for your changes:
   ```bash
   git checkout -b feat/my-awesome-feature
   ```
4. **Make Your Changes**: Add your guide improvements or examples.
5. **Commit Your Changes**: We recommend following the [Conventional Commits](https://www.conventionalcommits.org/) specification:
   ```bash
   git commit -m "docs: improve Let's Encrypt DNS challenge guide"
   ```
6. **Push and Open a Pull Request**: Push your branch to GitHub and open a pull request against the main repository.

## Contribution Guidelines

- **Code Quality**: Ensure any Docker Compose files are clean, standard, and easy to read.
- **Documentation**: Keep the offline-first guides markdown-formatted, using relative links for references between chapters.
- **Conventional Commits**: Try to use standard prefixes like `docs:`, `feat:`, `fix:`, or `refactor:` in your commits.
